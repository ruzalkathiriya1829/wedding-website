# Wedding Website

Luxury Digital Wedding Invitation Website for Sikh / Punjabi Anand Karaj Wedding.

## Folder Structure

- `punjabi_wedding_website/`
  - `index.html` — Full responsive interactive wedding invitation with video loop, audio, scratch-to-reveal countdown, celebrations, and travel guides.
  - `assets/` — High-resolution posters, animations, wedding music, and stylesheets.

## Features

- **Opening Film & Sound**: "Tap to Open Invitation" with ambient background music and smooth video loop.
- **Interactive Scratch Card**: HTML5 Canvas scratch-to-reveal live countdown timer.
- **Family Blessings**: Ornate arch invitation card with Ik Onkar (ੴ) blessings.
- **The Celebrations**: Complete event details with high-resolution visual cards:
  - Phoolon Ki Haldi
  - Sagai & Sangeet
  - Anand Karaj (Laavan Phere)
  - Saat Vachan
  - After Party
- **The Wedding Wardrobe**: Interactive wardrobe attire guide carousel.
- **Your Journey**: Accordion travel guide (By Air, By Train, By Road & Ferry) + Google Maps directions.
